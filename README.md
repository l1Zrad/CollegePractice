## Цель проекта
Разработка и развёртывание работающего виртуального прототипа системы автоматизации и мониторинга для нового офиса в среде **GNS3**. Проект включает в себя проектирование логической и физической топологии сети, настройку сетевого оборудования Cisco, развёртывание инфраструктуры на базе **РЕД ОС 8** и **Windows Server 2019**, а также программную имитацию IoT-устройств (датчиков и исполнительных механизмов) и логики их взаимодействия в **Node-RED**.

---

## Роли устройств в проекте

Инфраструктура состоит из сетевого оборудования (Cisco SW, Cisco RTR) и 5 ключевых узлов:

*   **WIN (Windows Server 2019)** — Рабочее место администратора. Используется для управления инфраструктурой, настройки, мониторинга и контроля работоспособности всей системы умного офиса.
*   **CTRL (РЕД ОС 8)** — Центральный контроллер системы управления. На нём сосредоточена основная бизнес-логика (Node-RED), которая обрабатывает показания датчиков и автоматически управляет исполнительными механизмами (например, включением охлаждения при повышении температуры). Также выступает в роли шлюза для сбора файлов по SCP.
*   **IOT (РЕД ОС 8)** — Сервер имитации IoT-устройств. На базе Node-RED программно моделирует работу датчика температуры (`TEMP`) и вентилятора (`FAN`) в серверной, датчика влажности (`HUM`) в рабочей зоне, а также других умных устройств объекта. Состояние устройств передаётся в текстовом виде (`ON`/`OFF`).
*   **MON (РЕД ОС 8)** — Сервер мониторинга. Отвечает за сбор, визуализацию и отображение метрик состояния оборудования, сети и показателей датчиков, позволяя администратору следить за системой в реальном времени.
*   **DB (РЕД ОС 8)** — Сервер баз данных. Используется для структурированного хранения истории показаний датчиков, логов состояний вентилятора и других IoT-устройств, а также системных журналов.

## Структура репозитория
*   `/src` — Исходный код программных моделей, конфигурации Node-RED.
*   `/schemas` — План помещения (Remplanner/Draw.io) и логическая схема сети (GNS3/Draw.io).
*   `/configs` — Текстовые конфигурации сетевого оборудования Cisco и операционных систем.
*   `/docs` — Доказательства проверок (скриншоты, логи).
*   `journal.md` — Ежедневный отчёт о проделанной работе.
*   `.gitignore` — Исключение приватных данных (пароли, ключи, SQLite БД).
